# Ubuntu install Sysdig

:::info
:bulb: This template is for onboarding new recruits. 
:::

## 1. 安裝Sysdig

輸入以下指令安裝Sysdig

```
sudo apt update
sudo apt install -y sysdig
```
## 2. 執行Sysdig
<!--  -->
```
sudo sysdig
```
正常執行後會顯示許多資訊像如下圖
![Screenshot from 2025-03-26 20-19-20](https://hackmd.io/_uploads/Skm5MOZpJe.png)

若是出現以下錯誤，代表Sysdig 內核模組 (scap driver) 沒有正確安裝或載入
```
Unable to load the driver
error opening device /dev/scap0. Make sure you have root credentials and that the scap module is loaded: No such file or directory
```
